# Task API

A simple CRUD REST API built with Python and FastAPI.

This project was developed as part of the FlyRank Internship Backend Track Week 2 Assignment A1.

The API provides functionality to create, read, update, and delete tasks. Data is stored in memory and is reset whenever the server restarts.

## Features

- Create tasks
- Read all tasks
- Read a task by ID
- Update tasks
- Delete tasks
- Input validation
- HTTP status codes
- Interactive Swagger UI
- In-memory task storage

## Technologies

- Python
- FastAPI
- Pydantic
- Uvicorn
- Swagger UI
